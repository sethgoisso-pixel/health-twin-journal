# Health Twin Journal

Create a simple web app called "Health Twin": a personal health journal with a profile page (age, sex, blood group, height, weight), a daily log (meals, medications, sleep hours, water, symptoms), and a dashboard. Use TanStack Start, React, and Tailwind. Keep all data in the browser's localStorage. Clean, calm design.
